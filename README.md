# Orrery

**An agent-native investment research terminal for Claude** — own-engine charting (~125 indicators), analyst-grade factor screening, institutional portfolio analytics, driver-based company operating models, and a probability-weighted thesis engine — all introspectable and driven by the agent. Powered by Financial Modeling Prep, FRED, and SEC EDGAR.

> ⚠️ **Not investment advice.** Orrery is an informational research tool. Nothing it produces is advice or a recommendation; data and computations may be inaccurate — verify everything independently. ## Download & install

Grab the latest `orrery.plugin` from the [**Releases**](https://github.com/pauljbernard/orrery/releases/latest) page, then install it in Claude desktop (Settings → Capabilities) and restart your session.

Requires **Node.js ≥ 18** (the bundled MCP server has zero npm dependencies).

Full install / update / uninstall instructions are in the [**User Guide**](https://pauljbernard.github.io/orrery/guide.html).
