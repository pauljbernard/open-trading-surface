One tool, the whole workflow

From a market view to a modeled position — top to bottom, all agent-operable.

📐 Company operating models

Every company can carry a driver-based model calibrated from its filings and consensus. Turn any event into an instant answer.

  • Revenue → EBIT → EPS → FCF, five years out
  • Blended exit-multiple + DCF fair value
  • Shock any driver — tariffs, contract wins, rate moves — and see the fair-value delta
  • An elasticity table showing exactly what moves the stock

🧭 A thesis engine that keeps score

A maintained worldview feeds candidate theses with explicit probabilities and an evidence ledger that updates them as the world changes — the system even proposes its own from FRED macro data.

  • Probability-weighted, not vibes
  • Every development logged as evidence that moves the odds
  • Compiles into screens and paper model portfolios

💼 Institutional portfolio analytics

The measurement core professionals expect — verified against closed forms.

  • Time-weighted vs money-weighted returns
  • Carino-linked Brinson attribution
  • Ex-ante factor risk, mean-variance optimization
  • FIFO tax lots, broker CSV import, dividend reconciliation

Install in two minutes

Two ways, depending on how you run Claude.

Claude desktop (Cowork)

  1. Download the packageGrab the latest orrery.plugin from Releases.
  2. Install itOpen it in the app, or add it under Settings → Capabilities, and restart the session.
  3. Add your keys in the ⚙ Settings tabPaste your FMP key (and a free FRED key), hit Test. Keys never leave your machine.
  4. Accept the terms & goAcknowledge the one-time disclaimer, then ask the agent to open the terminal.

Claude Code (CLI)

claude plugin marketplace add pauljbernard/orrery-marketplace
claude plugin install orrery@orrery

Requires Node.js 18+. Stay current: the plugin tells you when a new version ships. Update & uninstall guide →
