User Guide

Everything you need to install, configure, use, update, and remove Orrery.

Requirements

  • Node.js 18 or newer — the plugin's local server has zero npm dependencies.
  • A Financial Modeling Prep API key — for market and fundamental data.
  • Optional: a free FRED API key — unlocks the macro signal engine and system-proposed theses. Register free.

Installing

Claude desktop (Cowork)

  1. Download the latest orrery.plugin from Releases.
  2. Open it with the desktop app, or add it under Settings → Capabilities.
  3. Restart the session so the plugin's local server starts. Tools then appear as mcp__orrery__*.

Claude Code (CLI)

claude plugin marketplace add pauljbernard/orrery-marketplace
claude plugin install orrery@orrery

Configuring API keys

The easiest path is in the UI: open the terminal, click the ⚙ Settings tab, paste your FMP key (and optionally FRED), and press Test to confirm live connectivity. You can also set FMP_API_KEY / FRED_API_KEY environment variables, which take precedence.

Keys are stored on your machine in ~/.orrery/config.json with file mode 600 and are never transmitted anywhere but the data providers themselves.

First run & the disclaimer

On first launch the terminal presents a one-time legal acknowledgment. You must read and accept it before using the application. A short disclaimer stays visible in the footer at all times, and the full terms live on the Legal page.

Orrery is not investment advice. Every output is a decision aid to be independently verified. You bear full responsibility for all investment decisions.

Using the terminal

Ask the agent to open the terminal. Across the top are per-security tabs plus pinned tabs for Portfolios, Screener, Watchlists, and Theses, a ⚙ Settings tab, and an ✉ Agent button to leave the agent a message. Each security tab has a left rail: Stock Chart, Company Info, Financial Statements, Analyst Ratings, Peer Comps, Ownership, Transcripts, News, SEC Filings, Insider Trades, Operating Model, and Research Notes.

Working with the agent

The agent operates every surface for you. A few things to try:

  • "Build an operating model for CAT and shock gross margin down 2 points."
  • "Screen large-cap industrials for quality and momentum, sector-neutral."
  • "Create a thesis from this view, set a probability, and build its model portfolio."
  • "Give me a morning brief" or "what's on my calendar this week?"
  • "Import my broker CSV and reconcile dividends."

Updating

 Claude desktop (Cowork)Claude Code (CLI)
CheckAsk the agent to check_for_updates; the workspace cockpit also flags new versions automatically.claude plugin update
ApplyDownload the new .plugin, install it, restart the session.claude plugin update orrery
Update checks are non-blocking and only request a version number — they never transmit your data. Your settings, portfolios, theses, and notes persist across updates.

Uninstalling

  • Cowork: Settings → Capabilities → remove Orrery.
  • CLI: claude plugin uninstall orrery
  • To also erase local data, delete the ~/.orrery/ directory (this removes your keys, portfolios, theses, notes, and models).

Your data & privacy

Everything lives in ~/.orrery/ on your machine: keys, portfolios, watchlists, theses, notes, company models, alerts, an audit journal, and test reports. Nothing is uploaded to any server operated by the publisher. The only outbound calls are read-only requests to your chosen data providers (FMP, FRED, SEC EDGAR) and a version-number check to the update channel.

Troubleshooting

  • Tools don't appear: restart the Claude session after installing; the MCP server starts on session load.
  • "No API key configured": add your FMP key in the ⚙ Settings tab and press Test.
  • Charts show no live data when opened from a saved file: by design, saved files never embed your key; open the live terminal URL the agent provides for live data.
  • SEC filing fetch returns 403: set an EDGAR contact in ⚙ Settings (e.g. "Your Name your@email.com").
  • Something looks wrong: ask the agent to run_test_suite, and open an issue.
